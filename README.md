# Game5 — game5.fun

On-chain gaming on **Robinhood Chain** (chain ID 4663). Token **$GAME5** · X: [@Game5Fun](https://x.com/Game5Fun)

## Update Contract Addresses
Edit `config.js` → `token.contract`. Commit to `main` and Vercel deploys automatically.

Social links, the Uniswap buy link and Robinhood Chain RPC/explorer are also in `config.js`.

## Structure
- `index.html` — main page
- `assets/style.css`, `assets/app.js` — UI and games (Dice, Coin Flip, Crash, Mines, Wheel)
- `config.js` — contract address, links, chain settings
